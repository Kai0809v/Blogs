# 👋 关于我

你好呀！欢迎来到我的个人博客 ✨

我是一名电气工程及其自动化专业的大四本科生 🎓，扎根于电气与嵌入式领域 ⚡，同时跨界探索软件开发与数据科学 💻。比起在单一方向深耕，我更享受从底层硬件到上层应用、从工程实现到算法优化的**全链路技术探索**——既能画电气图纸、焊单片机电路 🔧，也能写桌面应用、调时序预测模型 📈。

## 🛠️ 技术栈与能力版图

### ⚡ 电气 & 嵌入式开发

熟悉 STM32、51等主流单片机，精通 Keil 开发环境，可独立完成从硬件选型、原理图设计到代码调试的完整项目 🔌；

熟悉电路、模电数电、电机学、电力系统分析、继电保护、PLC、自动化等专业课程，具备电气一二次主接线设计能力，熟练使用 AutoCAD 完成工程绘图 📐。

‍

### 💻 全栈软件开发

掌握 Python、C、Kotlin 多语言开发能力：

* 🖥️ **桌面端**：基于 PySide6 开发跨平台 GUI 工具
* 📱 **移动端**：用 Kotlin 构建 Android 原生应用
* ⚙️ **工程化**：熟练使用 Git 做版本控制，擅长 Windows 系统调优、开发环境配置与故障排查

‍

### 📊 数据科学 & 学术研究

研究方向聚焦 **可再生能源时序预测** 🌬️，围绕风力、光伏发电功率预测开展了大量实践，对 Informer、TFT、TimesNet 等时序预测模型有深入的落地经验 🧠；探索过 EWT 经验小波变换、异常数据清洗等特征工程方法对长步长预测精度的提升 🔍。

## 🔥 一个热爱折腾的技术爱好者

除了专业学习和科研，我大部分业余时间都花在“折腾技术”上 🤓。

热衷于挖掘老旧设备的潜力 ♻️，比如给手机刷入 LineageOS、澎湃 ROM 等第三方系统 📲，用 Termux 搭建随身 Linux 环境 🐧，部署 Alist 内网网盘 ☁️，调试 Magisk 模块、折腾 ADB 与 SSH 深度排错 🔧——把备用机玩成便携的 Linux 工作站，是很有意思的事。

闲暇时也喜欢登山与象棋：登山锻炼耐力，在徒步中放空思绪；象棋锻炼逻辑推演，习惯在落子间权衡取舍，两种爱好也潜移默化影响着我做工程与算法时的思考方式。

课外我也累计完成了 **63 小时** 社区志愿服务 🤝，相信技术可以解决问题，而温度能让技术走得更远 ❤️。
